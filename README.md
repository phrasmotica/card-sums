# Card Sums

## Concept

* Each round is a gauntlet of random sums involving addition, subtraction, multiplication and division
* Each sum contains 3 or 4 numbers and operators between them
* To solve a sum, you have to play a card from your hand
* Each card contains some set of integers - a continuous range, a few specific numbers, etc
* The card you play must contain the answer to the sum in its set of integers
* If a sum appears that you can't solve with a card in your hand, you can apply some buff to the card to alter its set of integers
* These buffs can be purchased from a shop between rounds
* Shop purchases require currency, which is accrued by solving sums during rounds
